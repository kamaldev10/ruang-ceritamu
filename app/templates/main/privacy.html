Kebijakan Privasi {{ app_name }}

Terakhir diperbarui: {{ current_year }}

1. Data yang Kami Kumpulkan

Saat Anda mendaftar, kami mengumpulkan: username (samaran), alamat email, dan password yang terenkripsi. Kami tidak mengumpulkan nama asli, alamat, nomor telepon, atau identitas resmi lainnya kecuali Anda secara sukarela mengisinya di profil.

Saat menggunakan layanan: isi pesan chat (dienkripsi di database), cerita forum, catatan mood, dan metadata teknis (IP address, waktu akses) untuk keamanan.

2. Bagaimana Data Digunakan

Data Anda digunakan untuk: menyediakan layanan curhat anonim, mencocokan Anda dengan pendengar, moderasi konten, deteksi situasi krisis untuk keselamatan, dan peningkatan layanan. Kami tidak pernah menjual data Anda kepada pihak ketiga.

3. Penyimpanan & Keamanan

Data disimpan di server yang dilindungi. Password dienkripsi satu arah (hashed). Sesi chat disimpan selama akun aktif. Log audit disimpan maksimal 1 tahun.

4. Hak Anda (UU PDP Indonesia)

Sesuai Undang-Undang Perlindungan Data Pribadi (UU No. 27 Tahun 2022), Anda berhak untuk:

✅ Mengakses data pribadi Anda yang kami simpan

✅ Memperbarui data yang tidak akurat melalui halaman Pengaturan

✅ Menghapus akun Anda kapan saja (menu Pengaturan, lalu Hapus Akun)

✅ Menarik persetujuan atas pemrosesan data

✅ Mengajukan keluhan kepada otoritas perlindungan data

5. Retensi Data

Data akun aktif disimpan selama akun tersebut aktif. Saat Anda menghapus akun, data pribadi (username, email, bio) akan dianonimkan secara permanen. Riwayat chat dan postingan forum akan tetap ada dalam bentuk anonim.

6. Cookie

Kami menggunakan cookie sesi untuk menjaga status login Anda. Kami tidak menggunakan cookie pelacakan atau iklan pihak ketiga.

7. Kontak

Untuk pertanyaan terkait privasi, hubungi: privasi@ceritakita.id
